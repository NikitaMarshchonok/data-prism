# VibeDash - Data Prism v2

VibeDash - это слой Prompt→Dashboard для Data Prism v2, который позволяет создавать интерактивные дашборды из текстовых описаний и CSV файлов.

## 🚀 Быстрый старт

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск приложения
```bash
export FLASK_APP=web_app.py
flask run
```

Откройте http://localhost:5000/vibedash в браузере.

### Опционально: Ollama для AI-анализа
```bash
# Установка Ollama (macOS)
brew install ollama

# Запуск модели
ollama run llama3

# Включение Ollama в приложении
export USE_OLLAMA=true
```

## ✨ Возможности

- **🤖 AI-анализ**: Автоматический парсинг промптов в спецификацию дашборда
- **📊 Интерактивные графики**: Plotly графики с возможностью масштабирования
- **📁 Экспорт в HTML**: Самодостаточный файл для офлайн просмотра
- **🎯 KPI метрики**: Автоматический расчет ключевых показателей
- **🔍 Умные фильтры**: Автоматическое определение фильтров по данным
- **💡 AI-комментарии**: Автоматические комментарии к графикам

## 📝 Использование

### 1. Загрузка данных
Загрузите CSV файл через веб-интерфейс.

### 2. Описание дашборда
Опишите, что хотите увидеть, например:
- "Создай дашборд продаж с основными KPI, топ-10 категорий по выручке, трендом по месяцам и фильтром по регионам"
- "Финансы: сумма дохода и расходов, дельта, тренд по неделям, топ-категории расходов"

### 3. Быстрые шаблоны
Используйте предустановленные шаблоны:
- **💰 Продажи**: KPI, категории, тренды, регионы
- **💼 Финансы**: Доходы, расходы, дельта, тренды  
- **🏠 Недвижимость**: Цены, комнаты, города, улицы

### 4. Экспорт
Скачайте самодостаточный HTML файл для офлайн просмотра.

## 🔧 Архитектура

### Компоненты
- **`vibedash/spec.py`**: Pydantic модели для VizSpec
- **`vibedash/ollama_client.py`**: Клиент для локального LLM
- **`vibedash/generator_bridge.py`**: Мост к существующему генератору
- **`vibedash/exporter.py`**: Экспорт в single-file HTML
- **`vibedash/routes.py`**: Flask routes

### Формат VizSpec
```json
{
  "title": "Название дашборда",
  "metrics": [
    {"title": "Общая сумма", "expr": "sum(Sales)", "fmt": "currency"}
  ],
  "charts": [
    {"type": "bar", "x": "Category", "y": "Sales", "agg": "sum"}
  ],
  "filters": [
    {"field": "Region", "values": ["North", "South"]}
  ],
  "comments": ["Комментарий к дашборду"]
}
```

## ⚙️ Конфигурация

### Переменные окружения
```bash
USE_OLLAMA=false              # Использовать Ollama для AI-анализа
OLLAMA_MODEL=llama3          # Модель Ollama
MAX_ROWS_PREVIEW=100000      # Максимум строк для предварительного просмотра
```

### Поддерживаемые типы графиков
- `bar` - Столбчатая диаграмма
- `line` - Линейный график
- `area` - Диаграмма с областями
- `scatter` - Точечная диаграмма
- `hist` - Гистограмма
- `pie` - Круговая диаграмма

### Поддерживаемые агрегации
- `sum` - Сумма
- `mean` - Среднее
- `count` - Количество
- `max` - Максимум
- `min` - Минимум
- `median` - Медиана

## 🔄 Интеграция с Data Prism v1

VibeDash полностью совместим с существующим функционалом Data Prism v1:
- Существующие маршруты (`/`, `/dashboard`) работают без изменений
- Использует тот же генератор дашбордов
- Сохраняет все существующие возможности

## 🐛 Устранение неполадок

### Ollama недоступен
- Убедитесь, что Ollama запущен: `ollama serve`
- Проверьте доступность: `curl http://localhost:11434/api/tags`
- Приложение автоматически переключится на эвристический парсинг

### Ошибки парсинга промпта
- Используйте более конкретные описания
- Указывайте названия колонок из CSV
- Попробуйте предустановленные шаблоны

### Проблемы с экспортом
- Убедитесь, что папка `exports/` существует
- Проверьте права на запись
- Для больших файлов увеличьте `MAX_ROWS_PREVIEW`
